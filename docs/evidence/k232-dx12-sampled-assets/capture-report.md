The workload includes two zoom-control clicks, frame barriers and bounded preparation-idle observations. Texture creation is nested within asset upload; the parent also includes packing, staging/command recording, descriptors and remaining cache/loop work. Cache eviction is a separate CPU scope outside that parent. Child fractions of upload are not fractions of the whole workload. CPU API wall time is not GPU execution time. Cache entry/charged-byte fields are gauges and are not summed as upload events.

All four workload captures reported 1238 cache misses/texture creations/arena uploads/evictions, 248 cache hits, 1256 descriptor pairs, zero dedicated uploads, 14,143,488 padded upload bytes and 11,762,496 source upload bytes. Sessions were finalized with zero drops, boundary exclusions or in-flight observations. Mixed records include input dispatch and UI updates; they are not rendered-frame counts. Idle captures may contain zero records without forcing redraws. The archived descriptive two-observation means retain the A1 outlier; four noisy runs do not support a statistical estimate or instrumentation-overhead claim.

Baseline/candidate corresponding before and after PNGs each decode to exactly equal 1404×1257 RGBA pixels, with no region excluded. Every run's own before/after comparison has 4611 different pixels in the observed half-open bounding box `[589,1147,692,1196]`, confined to the zoom-in control highlight. Therefore a whole-image round-trip equality claim is not made. The page, zoom 14%, pan `(128.6,48.0)`, 1492 visible/render instances, Canvas bounds `[360,138,1404,1257]`, physical window 2160×1440 and observed scale 1.5 match. Window position is not exposed by MCP and is not asserted. The after-state `pending_bytes=4272928` is a historical last-paint snapshot, not a live queue-drain measurement. Readiness uses open/no-error, full instances, preparation idle and stable state; completed CPU passes and bounded successful PNG readback supply separate witnesses.
