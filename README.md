# Issue assets

Screenshots and minimal repro examples for issues filed against lurq. This branch is not code: the issues link to the files here.

- `0.67.0/repro/`: a standalone cargo project (`cargo run --example <name>`), lurq 0.67.0 with `winit`, `wgpu` and `mcp`.
- `0.67.0/shots/`: screenshots of the examples, taken on Windows 11 at display scale 1.5.

The fonts in `0.67.0/repro/fonts/` are Geist and Geist Mono 1.7.2 by Vercel, under the SIL Open Font License (`GeistMono-OFL.txt`).
